# Checkin

Android-приложение для ежедневной самонаблюдательной записи: настроение, энергия, тревожность, стресс, сон, привычки и заметки. Все данные хранятся **только на устройстве**; приложение ничего не отправляет в сеть (в манифесте нет разрешения INTERNET).

> Приложение не является медицинским изделием и не заменяет консультацию специалиста.

## Возможности

- Быстрая запись за день: шкалы, привычки, причины, заметка с хэштегами
- Статистика: тренды, недельная сводка, тепловая карта настроения, поиск закономерностей (перестановочные тесты + поправка на множественные сравнения)
- Мини-эксперименты: «попробовать реже/чаще» привычку на 14 дней
- Тест личности IPIP-NEO-120
- Напоминания с быстрой записью настроения прямо из уведомления
- Блокировка по PIN и биометрии
- Экспорт: JSON, JSON с паролем (PBKDF2 + AES-256-GCM), CSV, PDF-отчёт, текст для анализа нейросетью

## Сборка

1. Открой папку проекта в Android Studio.
2. Дождись синхронизации Gradle (wrapper скачает нужную версию сам).
3. Запусти конфигурацию `app` на устройстве или эмуляторе (minSdk 26).

Тесты: `./gradlew testDebugUnitTest` и `./gradlew connectedDebugAndroidTest`.

## Приватность

- Данные лежат во внутреннем хранилище приложения без шифрования; PIN защищает вход, а не файл. Для переноса и резервных копий используй экспорт с паролем.
- Облачный бэкап Android отключён; разрешён только перенос на новый телефон.
- Экспорт «для нейросети» формируется локально, а отправляешь его ты сам — проверь текст перед отправкой.
