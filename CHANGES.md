# Правки по аудиту (раунд 2)

Не собиралось и не запускалось (в среде нет Kotlin/Gradle): код проверен чтением и проверкой баланса скобок.
Перед релизом: `./gradlew testDebugUnitTest connectedDebugAndroidTest`.

## Безопасность и приватность
- **Lock.kt / MainActivity.kt**: PIN больше не обходится пересозданием Activity (поворот экрана, смена темы/шрифта,
  уничтожение Activity системой). Время ухода в фон хранится в `Lock`, а не в Activity; при блокировке по таймауту
  сбрасывается `unlockedThisProcess`. Поворот экрана (`isChangingConfigurations`) уходом из приложения не считается.
- **Lock.kt**: пауза после ошибок PIN переживает перезагрузку (рядом с `elapsedRealtime` хранится настенное время и
  `boot_count`). Выход в пикер/«поделиться» даёт ограниченную отсрочку (минимум 5 минут), а не «никогда не блокировать».
- **Lock.kt**: «Забыл PIN?» принимает только пароль/PIN/графический ключ устройства (без слабой биометрии);
  сброс PIN больше не стирает настройки задержки и блокировки скриншотов.
- **Storage.kt**: «Удалить ВСЕ» теперь удаляет записи, результаты теста, эксперименты, автокопии, копии повреждённых
  файлов и черновик теста.
- **AiExport.kt**: хэштеги (они берутся из текста заметок) не уходят наружу, когда заметки выключены.
- **backup_rules.xml / data_extraction_rules.xml**: облачный бэкап исключён по каждому домену явно
  (`root` один не покрывает file/sharedpref/database).

## Данные
- **Experiments.kt**: исправлен перевёрнутый вердикт для цели «реже»; проверка «привычка действительно изменилась»
  теперь сравнивает с 14 днями до эксперимента (для «реже» раньше предупреждение срабатывало при успехе).
- **Insights.kt**: подсказка-эксперимент создаётся только для находок про настроение (для «тревожности» направление
  было обратным). Убрано центрирование «по времени суток» (считалось по времени последней записи дня и не делало того,
  что обещал текст); тексты исправлены. Дни недели: лучший/худший и разница считаются по одному набору дней.
- **CheckinScreen.kt**: при смене времени записи сон не остаётся на не-утренней записи (скрытые показатели при
  правке сохраняются); новая запись начинается с пустых ползунков (раньше копировала значения прошлой записи и
  сохраняла их, хотя пользователь на вопросы не отвечал); время/дата не «застревают» после ночи.
- **Storage.kt**: черновик теста не воскресает после завершения (удаление идёт через тот же writer); импорт
  отвергает некорректные шкалы (step ≤ 0, max ≤ min, NaN) вместо вечного краша; NaN в значениях не ломает сохранение.
- **Storage.kt / Screens.kt**: если файл данных был повреждён, а первым запуском было уведомление (без UI),
  сообщение об этом теперь доживает до первого открытия приложения.
- **Settings.kt**: экспорт не создаёт пустой файл с сообщением «сохранён»; импорт ограничен 20 МБ; сборка данных для
  нейросети вынесена с UI-потока.
- **Crypto.kt**: неподдерживаемое число итераций даёт понятную ошибку, а не «неверный пароль».

## Экспорт
- **Report.kt**: CSV с точкой в числах при любой локали (на русской было «6,5» и сдвиг столбцов) и защитой от формул;
  PDF переносит длинные строки и не рвёт эмодзи.
- **Storage.kt / Reminder.kt / Screens.kt**: машинные форматы времени не зависят от локали (`hhmm`).

## Интерфейс
- **Charts.kt**: тепловая карта заканчивается текущей неделей (раньше до 6 последних дней, включая сегодня, не показывались).
- **Screens.kt**: смена вкладки закрывает открытые подэкраны; исправлено определение значка тренда.
- **Ui.kt**: удаление своего показателя/привычки/причины требует подтверждения.
- **Stats.kt**: в карточке поддержки добавлен номер 112 / местная кризисная линия.
- **Reminder.kt**: после срабатывания заново ставится только сработавший слот; у кнопок уведомления есть иконка.
- **Questions.kt**: число шагов слайдера считается с округлением (раньше 0,7/0,1 давало на шаг меньше).
- Подписи частей суток («с 5 до 11» и т. д.), опечатка «бала», тёмный фон окна при запуске (values-night).
- Удалён мёртвый пакет `ui/theme` и шаблонные Example-тесты.

## Тесты
- Новые в AnalyzerTest: вердикт эксперимента, тепловая карта, CSV, локаль, шаги слайдера, границы частей суток.
- Тесты, использующие `org.json`, перенесены в androidTest (`StorageInstrumentedTest`): в JVM-тестах это заглушка.

## Сознательно не менялось
- Автоблокировка по-прежнему убирает `AppRoot` из композиции, поэтому несохранённая форма при блокировке теряется
  (оставлять содержимое в композиции под экраном блокировки хуже для приватности: TalkBack).
- Данные на диске не шифруются (PIN защищает вход, а не файл) — так задумано и написано в настройках.
- Мёртвый код `generateDemo`/`deleteWhere` оставлен.
- Дубли названий показателей в AI-экспорте (одинаковые названия сливаются в один ключ JSON).
